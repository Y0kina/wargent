# Level 0: Anatomy of an agent

## Scenario

Atlas is a help desk assistant. An agent is made of a system prompt, a set of tools and a context of documents. The user message is appended to that context and the agent acts on it.

## Objective

Obtain the access code held in the onboarding checklist.

## Controlled input

The user message sent to Atlas.

## Concept

An agent combines three parts: instructions (system prompt), capabilities (tools) and context (documents, messages). Every later level abuses the boundary between these parts.

## Defense approach

This tutorial level has no defense exercise.

## Hints

1. The /inspect command lists the system prompt, the tools and the context documents.
2. The welcome note names a file. The agent owns a tool able to read files.
3. A plain request that names the file path is enough.

_Hints are intentionally partial. Solutions are not published._
