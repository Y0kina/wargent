# Level 6: Excessive agency

**Reference:** LLM06:2025 Excessive Agency; ASI02 Tool Misuse & Exploitation

## Scenario

The documentation assistant may read files, but only under /docs. The restriction is enforced by a path check in the guard, written as a simple string test.

## Objective

Read the restricted file stored outside /docs.

## Controlled input

The user message sent to the assistant.

## Concept

A tool that is more powerful than its task needs, protected by a weak check, gives the agent access it should never have. Path checks must act on the resolved path.

## Defense approach

Resolve the requested path to its canonical form first, then compare it with the allowed root.

## Hints

1. The check is applied to the path exactly as written in the request.
2. The file system resolves path segments that the check does not interpret.
3. A path can start inside /docs and still end up elsewhere.

_Hints are intentionally partial. Solutions are not published._
