# Code of Conduct

## Standard

Participation in this project is expected to be respectful, constructive and focused on the
work. Harassment, discrimination, personal attacks and deliberate disruption are not accepted.

## Scope

This applies to every project space: issues, pull requests, discussions and reviews.

## Enforcement

Maintainers may edit, hide or remove contributions that violate this standard and may restrict
participation. Reports go to the maintainers through a private GitHub security advisory or the
contact address listed on the maintainer profile.
